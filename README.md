## Odyssey training – January 2026 – Curriculum


### Day 1 : 2D editor basics

- Quick explanation : what’s Odyssey? (5min)
- Starting a new project with an Odyssey Template (5min)
- Basic interface: canvas, colour wheel and timeline (5min)
- Raster Animation Layers (30min)
    - The different Raster brushes and tools
    - Adding cells
    - Changing exposure values
    - Light-table & out-of-Pegs
    - Playing with Alpha channel 
    - Using the Raster Paint Bucket
    - Stagger cells vs Layer behaviours
    - Shortcuts
- Vector Animation Layers (60 min)
    - The different Vector brushes and tools
    - Making anther animation in Vector
    - Using Vector Paint Bucket with Palettes for indexed colours
    - The purpose of sets
    - The Vector Scene Tree View: organisation & settings
    - The Inbetweener (experimental)
    - Shortcuts
- Quick Q&A (15min)

### Day 2: 3D Editor basics

- Levels: explanation & creation (5min)
- Unreal Engine main tools (30min)
    - Navigating in the Viewport + various shortcuts & tips
    - Adding Actors & manipulating them
    - Outliner Panel
    - Details Panel
    - Content Browser / Drawer and its fundamental purpose
    - Ctrl+S vs Ctrl+Shift+S
- Creating a new 2D animation and adding it to the Level (30min)
    - Animating directly in the 3D Viewport
    - Understanding the Odyssey Editor Mode
    - The “Odyssey” Viewport
    - Using Marks & Flips
- Adding & Using a Level Sequence (30 min)
    - Explanation & creation
    - Cine Camera Actor: focal length, focus & aperture (yes, they matter!)
    - Transform tracks and keys
    - Parenting vs Constraints
- Using a 3D rigged character in the scene (20min)
    - Getting content from Fab ([MC Sample Animation Pack](https://fab.com/s/71059470c6ce))
    - Adding a 3D character and using a library of animations 
- Quick Q&A (5min)

          
### Day 3: Using the 2D animation actor in various contexts

- Introduction to Materials & Material Instances (30min)
    - Surface domains
    - Blending modes
    - Shading models
    - Main node (Diffuse, Roughness, Metallic, Emissive, Opacity, etc.)
    - Material Instances
    - Various tips and tricks
- Making a 2D FX animated by hand, combined with the 3D rigged character (30min)
    - Making a dedicated Material from scratch using Scalar Parameters
    - Controlling the Material’s parameters in a Level Sequence
- Making a 2D animation on a sphere to animate a character’s face expression (30min)
    - How to change the Mesh
    - How to attach the Animation actor to a body part
    - Making another Material from scratch
- Creating a fake shadow with a Decal (20min)
    - Media Textures & Media tracks
    - Making another Material from scratch
    - Animating the Decal in the Level Sequence
- Quick Q&A (10min)

### Day 4: Using Odyssey for pixel-art games

- Downloading [Cobra Code project](https://github.com/CobraCodeDev/TP_2DSideScrollerBP) (10min)
    - Changing UE versiong
    - Enabling Odyssey 
    - Testing the project
- Texture 2D, Tileset & Tilemap: explanations (15min)
- Editing existing Tilemaps (5min)
- Making a Tilemap from scratch (20min)
- Sprite animations with Flibooks (40min)
    - The “old” method
    - The Odyssey method
    - Tips & tricks
    - Changing all the flipbook animations from the project
- Using post-process volumes & Odyssey to change the mood / weather of the game (20min)
    - Mood: hurt, gloomy
    - Weather: fog, snow, rain
- Quick Q&A (10min)
